# Semantic Colab notebook

`02_Semantic_Training_Colab.ipynb` is a dated convenience snapshot copied from
`QRGuard_ML_Colab/02_Semantic_Training_Colab.ipynb`.

Upload `QRGuard_ML_Colab.zip` to Google Drive and run the notebook cells in order.
The Semantic notebook builds its generated cache from the documented sources; a
manual duplicate of the million-row processed dataset is not required in this
evidence folder.

The training and runtime paths use the same URL canonicalisation contract to avoid
the train–serve skew found in `semantic-2026.01`.
